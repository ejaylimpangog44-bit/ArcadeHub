# ArcadeHub
🎮 Arcade Hub

​A responsive, single-file frontend Arcade Hub built for GitHub Pages, containing a collection of lightweight, interactive mini-games. Designed with a clean dark-themed UI, an organized navigation layout, and zero external dependencies or backend requirements.

​✨ Features

​Single-File Architecture: Everything (HTML, CSS, and JS) is packaged into a single index.html file for seamless hosting on GitHub Pages.
​Responsive Multi-Row Navigation: Cleanly categorized button hub to easily switch between games.
​Mobile Sharing QR Code: Built-in QR code generator accessible via the upper-left corner button on each game screen, allowing you to instantly open and test the hub on mobile devices.
​Smooth Animations & Game States: Includes custom loading screens, winning line animations for Tic-Tac-Toe, and interactive canvas/grid mechanics.

​🕹️ Game Library

​❌⭕ Tic-Tac-Toe
​Modes: Play 2-Player local PvP or challenge the AI across multiple difficulty tiers (Easy, Normal, Hard with Minimax algorithm).
​Feature: Features an animated white strike-through line when a player connects a winning row.

​🦾🧸 Claw Machine
​Mechanic: Position the robotic arm using left and right controls, drop it down, and test your timing to retrieve collectible prizes into your inventory.

​🪨📄✂️ Rock, Paper, Scissors (PvP)
​Mechanic: A local 2-player showdown where players make secret moves by passing the device, complete with live round scorekeeping.

​🎯🔢 Number Guessing
​Mechanic: Guess the randomly generated number between 1 and 100 with real-time "Too High" or "Too Low" hints and an attempt tracker.

​🐹🔨 Whack-a-Mole
​Mechanic: Fast-paced reflex game where you tap randomly appearing moles within a 20-second timer to rack up the highest score.

​⚡⏱️ Reaction Timer
​Mechanic: Test your quick-click reflexes in milliseconds when the screen switches from wait-state red to ready-state green.

​🐍🟢 Snake Game
​Mechanic: Control a classic retro snake on an HTML5 canvas, eating food items to grow longer while avoiding walls and your own tail.

​🧺⭐ Item Catcher
​Mechanic: Move your basket left and right to catch falling stars and gems while dodging obstacles to protect your lives.

​🍬🍭 Candy Match-3
​Mechanic: Swap adjacent colorful candies on a grid to line up 3 or more matching items, scoring points before your moves run out!
